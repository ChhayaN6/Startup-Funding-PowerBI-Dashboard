# 📊 Startup Funding Trends & Investment Analysis | Power BI Project

## 📌 Project Overview
This project focuses on analyzing startup funding trends, investor activity, and industry growth patterns using an interactive Power BI dashboard. The dashboard provides insights into funding distribution across industries, cities, startups, and investment types, helping identify major trends within the startup ecosystem.

The goal of this project was to transform raw startup funding data into meaningful business insights through data cleaning, modeling, visualization, and interactive reporting.

---

## 🎯 Objective
Build an interactive dashboard to:
- Track startup funding trends over time
- Analyze industry-wise investment performance
- Identify top investors and funded startups
- Explore investment types and funding distribution
- Create an intuitive and interactive user experience

---

## 🛠 Tools & Technologies Used:
- **Microsoft Power BI**
- **Microsoft Excel**
- **Power Query**
- **DAX (Data Analysis Expressions)**

---

## 📈 Dashboard Features
- KPI Cards for overall funding insights
- Funding trend analysis by year
- Industry-wise investment analysis
- Top investors by funding amount
- Startup performance tracking
- Investment type distribution
- Interactive slicers and filters
- Page navigation buttons
- Tooltips and bookmarks for enhanced interactivity

---

## 📊 Key Insights
- Total funding analyzed exceeded **$38 Billion**
- Ecommerce emerged as one of the fastest-growing sectors
- Startup funding showed major fluctuations across years
- Certain investors and cities dominated startup investments
- Different funding stages contributed uniquely to startup growth
